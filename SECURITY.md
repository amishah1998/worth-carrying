# Security

Report a vulnerability privately through GitHub's security advisories on this repository, not in a public issue. You will get a reply within a week.

What the app holds: the search key on the server, a database of product prices it has looked up, and nothing about the people using it beyond an hourly counter per address that is never written to disk. A photo, when that feature is switched on by the operator, goes to the model provider and is not stored.
