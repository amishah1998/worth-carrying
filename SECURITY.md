# Security

Report a vulnerability privately through GitHub's security advisories on this repository, not in a public issue. You will get a reply within a week.

The app holds the search key on the server and a database of product prices it has looked up. About the people using it, it keeps only an hourly counter per address, in memory, never written to disk. A photo, when that feature is switched on by the operator, goes to the model provider and is not stored.
